THIRD-PARTY NOTICES
===================

Purpose
-------

This file lists third-party libraries and components used by Omega-LB and explains how to generate an authoritative, machine-readable list of licenses for each language/tooling area. It is not a replacement for including full license texts in binary releases; include a `NOTICE` / `THIRD_PARTY_NOTICES` bundle with each release.

Key repository areas scanned for dependencies:

- Python runtime and demo (`requirements.txt`, `dashboard/requirements.txt`, `ml/requirements.txt`, `desktop/requirements.txt`)
- Go control-plane (`controlplane/go.mod`)
- eBPF kernel code (`ebpf/` — C sources)
- Desktop packaging (`desktop/` — PySide6, PyInstaller)

How to generate exact license lists
----------------------------------

Python (pip-installed packages)

1. Create a clean virtualenv and install pinned dependencies:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

2. Install `pip-licenses` and export a machine-readable list:

```bash
.venv/bin/pip install pip-licenses
.venv/bin/pip-licenses --format=markdown --with-urls --output-file=THIRD_PARTY_PYTHON_LICENSES.md
```

This produces `THIRD_PARTY_PYTHON_LICENSES.md` containing package, version, license and homepage URL.

Go modules

1. Install `go-licenses` (Google):

```bash
go install github.com/google/go-licenses@latest
```

2. From the `controlplane/` module root run:

```bash
go-licenses csv ./... > THIRD_PARTY_GO_LICENSES.csv
```

eBPF and system tooling

Third-party C libraries and tools used to build eBPF (e.g., `libbpf`, `clang`, `llvm`, kernel headers) are platform-provided or upstream projects. Document these in releases and include their licenses when bundling any binary artifacts.

Desktop

The desktop app depends on `PySide6` and uses `pyinstaller` to produce a distributable. PySide6 is LGPL-style with exceptions (Qt licensing can be nuanced). When redistributing binaries, include the relevant Qt/PySide license and follow their packaging guidelines.

Recommended folder layout for release notices
-------------------------------------------

- `THIRD_PARTY_NOTICES.md` (this file) — high-level summary
- `THIRD_PARTY_PYTHON_LICENSES.md` — generated by `pip-licenses`
- `THIRD_PARTY_GO_LICENSES.csv` — generated by `go-licenses`
- `NOTICE` or `THIRD_PARTY_LICENSES_FULL/` — full license texts to bundle with binary releases
